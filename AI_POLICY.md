# AI POLICY
## Summary
Assistive AI tools are permitted. A human must always be in the loop. A human submitting an issue or PR is responsible for it's content. Disclosure of the use of generative AI in commits and PRs is appreciated but not required.
## Human authorship and accountability
Human authorship is a prerequisite for copyright. Contributors are responsible for all submitted content, regardless of whether generative AI tools were used. Humans must be able to discuss changes during pull request reviews. All code must comply with existing licensing.
## AI use disclosure
AI assistance can be disclosed using the following commit trailer:
`Assisted-By:[model version]` - use this when line and/or function auto-complete tools have been used, or when the developer has used an iterative prompt, review, edit process.
Similar language can be used in pull requests to disclose the use of generative AI.
